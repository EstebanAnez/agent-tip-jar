Agent Tip Jar

An AI agent with a Solana wallet. It pays for APIs over HTTP 402, tips people, and leaves an onchain receipt with a reason for every payment.

How it works

01

Ask

The agent calls a paid API.

02

HTTP 402

The API replies with a price, an address and a one time code.

03

Pay on Solana

SOL transfer plus the code as a memo, in one transaction.

04

Verified

The API checks the payment onchain, then answers. Replays are rejected.

05

Tip a human

The agent sends a thank you tip with a message onchain.

Under the hood

Stack

  • @solana/kit 8, System and Memo programs
  • Paid API with x402 style 402 challenge
  • Solana Developer MCP inside Claude Code
  • pay.sh tested in sandbox (blocked by its 504)

Safety rails

  • Devnet only, agent refuses payments over 0.01 SOL
  • One time nonces, expire after 5 minutes
  • Reused or fake signatures are rejected
  • No private keys in the repo
